# Submission privacy

This repository omits live operator credentials, private configuration, database files, runtime caches, raw agent transcripts, and private human request/approval text. Personal usernames and home/project/temp paths in diagnostics are replaced with neutral placeholders. It contains no full export of the human chat. Dummy credentials and sample addresses in tests remain as test fixtures.

Reports and verification output are privacy-redacted exports. Recorded evidence hashes and validation markers refer to the original immutable evidence retained privately; they do not assert that edited export contents have the original hashes. REPOSITORY-MANIFEST.json records checksums of the published assessment files, excluding the manifest itself. Candidate sources and application source are unchanged by this export cleanup.
